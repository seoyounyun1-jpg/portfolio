# Portfolio

데이터 분석/사이드 프로젝트 기록용 포트폴리오 저장소입니다.

## 폴더 구조

```
portfolio/
├── README.md
└── projects/                                # 프로젝트별 분석 기록
    ├── 호텔예약_취소노쇼_손실분석/
    │   ├── README.md                        # 분석 보고서
    │   ├── data/                             # 분석에 사용한 원본 데이터
    │   └── images/                           # 보고서에 삽입된 그래프
    ├── Olist_재구매율_하락원인분석/
    │   ├── README.md
    │   ├── data/
    │   └── images/
    ├── 크로스보더_진출우선순위분석/
    │   ├── README.md
    │   ├── data/
    │   └── images/
    ├── 서울시_따릉이_데이터_분석/
    │   ├── README.md
    │   └── [Codeit_team_project] 작업 파일.ipynb
    └── 피자가게_실전파이썬EDA_매출분석/
        └── [실전_파이썬_EDA]_피자_가게_데이터_분석.ipynb
```

- `projects/`: 모든 분석 프로젝트를 주제별 폴더로 모아둔 공간입니다. 폴더명은 어떤 분석인지 알 수 있도록 주제로 짓고 `분석`으로 통일했으며, 각 폴더 안에 분석 보고서(`README.md`), 분석에 사용한 원본 데이터(`data/`), 결과 시각화(`images/`)를 함께 둡니다.
- 각 프로젝트 폴더의 `README.md`에서 배경·분석 과정·인사이트·개선안을 확인할 수 있습니다.
