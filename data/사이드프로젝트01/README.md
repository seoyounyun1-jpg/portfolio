# Olist 재구매율 분석 — 데이터 파일

Brazilian E-Commerce (Olist) 공개 데이터셋을 가공한 분석 원본 엑셀입니다.
피벗테이블·계산 컬럼이 포함된 최종 분석 시트로, [프로젝트 상세 문서](../../projects/olist-repurchase-analysis.md)에서 다루는
가설 A(배송 지연)·가설 B(셀러 구조적 요인) 검증에 사용된 파일입니다.

## 파일

원본은 3개 시트를 담은 단일 파일(약 40MB)이었으나, GitHub 웹 업로드 용량 제한(25MB/파일)에 맞춰 **시트별 개별 파일로 분리**했습니다. 데이터 내용은 원본과 동일합니다.

| 파일 | 행 수 | 열 수 | 용량 | 내용 |
|---|---:|---:|---:|---|
| `주문_배송_리뷰.xlsx` | 99,441 | 23 | 17.6MB | 주문 단위 배송 리드타임, 지연 상태(`delay_status`), 리뷰 점수 등 |
| `품목_셀러.xlsx` | 112,650 | 13 | 10.3MB | 품목·셀러 단위 판매 데이터, 셀러 규모·평판 지표 |
| `고객단위_재구매분석.xlsx` | 94,990 | 20 | 12.1MB | `customer_unique_id` 기준 재구매 여부(`repurchase_flag`), 최초 주문 기준 파생 변수 |

> 참고: 분리 과정에서 원본 워크북에 포함돼 있던 서식(색상 등)은 제거되고 값만 남았습니다. 피벗테이블/차트는 원본 파일에도 없었고(순수 데이터 시트), 시각화 자료는 Notion 문서에 별도로 정리되어 있습니다.

## 원본 출처

- Kaggle: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) (2016–2018, 약 99,000건)
- 이 파일은 원본을 가공·병합·파생변수 추가한 최종 산출물이며, 원본 CSV는 용량·재현성을 위해 이 repo에는 포함하지 않았습니다. 필요 시 위 Kaggle 링크에서 동일 데이터로 재현 가능합니다.

## 참고

- LibreOffice에서 열 때 대용량 시트(품목_셀러, 112k행) 재계산 타임아웃이 발생할 수 있습니다 — Excel에서 여는 것을 권장합니다.
