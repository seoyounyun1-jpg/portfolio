## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 주제 | 서울시 따릉이 이용 편의 증대를 위한 서비스 운영 개선안 도출 |
| 팀 구성 | 6인 (김우상, 윤서연, 이현아, 이재빈, 단석진, 남예린) |
| 진행 기간 | 2026.08.28 ~ 2026.09.10 (14일, 협업 타임라인 기준) |
| 분석 데이터 기간 | 최근 1년 2025.07 ~ 2026.06 (전년 동기 2024.07 ~ 2025.06 과 비교) |
| 내 역할 | **이용자 분석 파트 리더** — 이용자 파트 데이터 수집·전처리·EDA·시각화 총괄, 팀 EDA/리포팅(Step 4·6) 담당 |
| 분석 축 | 이용자 · 시간 · 공간 3개 파트 병렬 진행 후 취합 |

**핵심 결론**

1시간 단위로 설계된 요금제가 실제 평균 이용시간(약 25분, 정기권 약 22분)과 맞지 않고, 계절성이 큰 이용 패턴에 비해 장기 정기권(180·365일권)에 일시정지 장치가 없으며, 자치구 간 거치대 수급 불균형이 뚜렷하다는 세 가지 문제를 확인하고 각각에 대한 개선안을 제시했다.

## 2. 분석 배경

- 데이터 분석이 가능한 최신 기간(2025.07~2026.06)과 직전 기간(2024.07~2025.06)의 대중교통 이용 추이를 비교한 결과, **버스·지하철 이용은 증가한 반면 따릉이만 유일하게 감소**했다. (출처: 월간통계보고서 2024~2026 | 서울TOPIS)
- 앱 기반 서비스라는 특성을 고려해 신규가입자 추이도 함께 확인한 결과, 직전 기간 대비 최근 1년간 **신규가입자 수도 8.7% 감소**했다.
- 이용·신규가입이 동시에 줄어드는 것은 따릉이에 대한 관심과 효용성이 떨어지고 있다는 신호로 판단하고, 이용 현황을 이용자·시간·공간 3개 축으로 분석해 현행 운영 방식의 문제점을 데이터로 확인하기로 했다.

## 3. 분석 프로세스

3개 파트(이용자 / 시계열 / 공간)를 병렬로 진행하고 마지막에 결과를 취합했다.

| 단계 | 내용 |
|---|---|
| 데이터 수집 | 서울 열린데이터광장·서울TOPIS·기상청·T-Data 등에서 따릉이 이용정보(시간대별/월별), 대여소·거치대 정보, OD 데이터, 신규가입자·외국인 대여, 기온·강수 데이터 확보 |
| 가설 수립 | 파트별 가설 리스트업 (예: 20~30대·정기권 중심 이용, 출퇴근 시간대 집중, 특정 자치구 쏠림) 후 최종 데이터프레임 형태 확정 |
| 전처리 | 인코딩(cp949) 정리, 완전중복행 제거, 원본 결측 구간(202502 파일 12일)을 일별 원본으로 실측 보완, 3개 파트 분석 기간을 최근 1년(2025.07~2026.06)으로 통일 |
| EDA | 파트별 분포·상관·시계열·공간 시각화, 전년 동기 대비 비교로 계절성에 의한 추세 왜곡 통제 |
| 취합 | 파트별 인사이트를 노션에 정리·링크 공유, 이용자 파트 코드를 하나의 파일로 병합, 보고서·발표자료·Tableau 대시보드로 종합 |

**데이터 전처리 참고**

- 따릉이 이용정보(시간대별) 2024.01~2026.06, 30개 파일 약 8,951만 행 규모 → 단순 결합 시 용량 과다로 월별 스트리밍 집계 방식으로 전처리
- 완전중복행 338건(2025.01~06 분산) 집계 전 제거
- `202502` 시간대별 파일에서 2/17~28(12일) 원본 자체 누락 확인 → 일별 원본으로 보완해 912일 전체 무결측 완성 (요일×시간대 테이블은 12일, 전체의 1.3%만 영향)

## 4. 주요 분석 결과

### 4.1 이용자

| 구분 | 결과 |
|---|---|
| 이용시간 분포 | 1회 평균 약 25분, 중앙값 약 12분. 전체 이용의 **42.49%가 10분 이내, 64.74%가 20분 이내**에 종료 |
| 요일별 평균 이용시간 | 평일 약 23.8분 / 주말 약 29.6분. 주말 오후 14~20시가 가장 길고 평일 출근 6~8시가 가장 짧음 |
| 연령대 | 20·30대가 전체 이용의 **56.5%**(과반). 10대 이하 6.5%, 60대 4.9%로 최저 |
| 성별 | 남성 이용량이 여성의 약 2배. 단 성별 미기재가 약 32%로 단정은 어려움 |
| 요금제별 이용 패턴 | 정기권(회원) **82.2%**, 일일권 약 17.5%, 가족권 약 0.2~0.4%. 회원 비중 약 99.2% |
| 요금제별 이용시간 | 이용량 1위 정기권의 1회 평균 이용시간이 **약 22분으로 전체 요금제 중 가장 짧음**. 3시간권 외 대부분 요금제 평균이 1시간 미만 |
| 외국인 | 외국인 평균 이용시간 약 65.9분 = 내국인(약 20.8분)의 3배 이상 → 관광 목적 이용 경향 |
| 상관관계 | 이용시간–이동거리 0.53(상대적으로 낮음), 이동거리–운동량·운동량–탄소량 각각 0.96 |
| 신규가입자 | 주말 신규가입이 평일의 약 1.5배, 20대가 요일 무관 최다. 겨울에 저조했다가 이후 가파르게 반등 |

### 4.2 시간

| 구분 | 결과 |
|---|---|
| 전년 동기 대비 | 전체 이용건수 **6.2% 감소**, 감소가 7월~1월 구간에 집중. 10월 감소폭 최대(약 465만 건 → 340만 건). 2월·봄(4~6월)은 전년과 비슷하거나 소폭 증가 |
| 계절성 | 겨울 일별 이용건수 중앙값 약 5.6만 건 vs 봄·여름·가을 11~13만 건. 여름은 장마철 강우일에 2~4만 건대 저조 이상치, 가을은 계절 내 변동폭 최대(약 2.7만~17.6만 건) |
| 날씨 | 기온–일별 이용건수 상관계수 **0.64**(20도 이상에서 증가세 둔화). 강수 있는 날은 이용건수가 뚜렷하게 낮음 |
| 평일·주말 시간대 | 평일은 오전 7~8시·오후 17~19시 출퇴근 집중, 주말은 오전 이후 완만히 상승해 오후 17시경 정점 후 하락 |

### 4.3 공간

| 구분 | 결과 |
|---|---|
| 자치구별 이용 | 강서구 > 송파구 > 영등포구 순으로 이용량 압도적. 강북구 등 일부 자치구는 매우 저조해 지역 간 격차 큼. 상위 자치구는 대여·반납 건수가 거의 동일(구 내 순환 이용) |
| 대여소 입지 | 이용량 상위 10% 대여소는 한강공원·주요 교통 거점을 따라 밀집, 하위 10%는 외곽 주거지에 산재해 뚜렷한 집중 패턴 없음 → 수요 대비 과잉 배치 가능성 |
| 자치구 내 수급 불균형 | 강남구·서초구는 초과 공급 대여소 수 1·2위로 전체 잉여 대여소의 약 20% 차지하나 초과 수요 대여소는 각각 5개·7개뿐(유휴 인프라 밀집). 노원구·강서구·영등포구·구로구·양천구는 거치대 부족(초과 수요) 두드러짐 |
| 송파구 | 초과 수요 1위이자 초과 공급 3위 → 타 자치구 예산 투입 없이 **구 내부 재배치만으로 불균형 해소 가능한 유일한 자치구** |

## 5. 개선안 및 기대 효과

### 5.1 30분 단위 요금제 신설

전체 이용의 64.74%가 20분 이내에 종료되고 정기권 평균 이용시간도 약 22분이라, 1시간 단위 요금제와 실제 이용 행태 사이 간극이 크다. 기존 1시간권보다 짧은 30분 단위 요금제를 신설한다.

| 구분 | 30분권(신설) | 1시간권 | 2시간권 |
|---|---|---|---|
| 7일권 | 1,500원 | 3,000원 | 4,000원 |
| 30일권 | 2,500원 | 5,000원 | 7,000원 |
| 180일권 | 7,500원 | 15,000원 | 20,000원 |
| 365일권 | 15,000원 | 30,000원 | 40,000원 |
| 일일권(회원) | 500원 | 1,000원 | 2,000원 |
| 일일권(비회원) | 500원 | 1,000원 | 2,000원 |

**기대 효과** — 1시간 단위로 과금되던 잔여시간 손해를 줄여 요금 공정성·만족도 제고, 기존 수익 구조를 크게 바꾸지 않는 저비용 개선책, 단시간 이용자의 진입장벽 완화로 이용건수·신규가입 증가 기여.

### 5.2 180일권·365일권 일시정지 제도 도입

180·365일권은 결제 시점부터 하루 단위로 이용 가능일수가 차감돼, 계약 기간에 겨울 비수기가 포함되면 이용자가 손해를 그대로 떠안는다. 장기 정기권에 사용기한 일시정지 기능을 부여한다.

| 구분 | 내용 |
|---|---|
| 대상 | 180일권·365일권 이용자 |
| 신청 방식 | 앱 내에서 이용자가 직접 신청 → 정지 기간만큼 만료일 자동 연장(추가 요금 없음, 기결제 잔여 이용기간 유예) |
| 최대 정지 가능일수 | 180일권 최대 30일 / 365일권 최대 60일 (겨울 비수기 약 90일 중 일부 커버, 무제한 유예 방지) |
| 안내 시점 | 겨울철 진입 시점(11월 말~12월 초) 앱 푸시 |
| 해제 방식 | 이용자 직접 재개 또는 최대 기간 도달 시 자동 재개 |

**기대 효과** — 겨울 비수기 손해를 이용자가 떠안지 않게 되어 정기권 만족도·재구매 유인 상승, 유휴 자원 구간이라 추가 운영비 거의 없음, 정기권 해지·미갱신 감소로 이용·신규가입 감소 문제에 직접 대응.

### 5.3 자치구 내 거치대 재배치

강남구·서초구의 회전율 낮은 초과 공급 거치대를, 거치대가 부족한 초과 수요 지점으로 재배치한다. 송파구는 구 내부 재배치를 우선 적용하고, 자치구 간 이관이 필요한 구간은 강남구·서초구 잉여 거치대를 인접 초과 수요 지역으로 순차 이전한다.

**기대 효과** — 유휴 상태의 초과 공급 거치대 재활용으로 회전율 개선, 신규 설치 예산 없이 기존 인프라 재배치만으로 불균형 해소, 출퇴근·환승 수요 지역의 대여 실패 경험 감소.
